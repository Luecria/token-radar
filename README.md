Token Radar ranks every pre-token protocol in a sealed DefiLlama snapshot by an implied launch value computed from its TVL, seven-day growth, tenure with no token, and chain breadth, and shows a concrete farm plan for each one.
## Run it
```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
